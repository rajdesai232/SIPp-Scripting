SIPp scenario files "fetch" the pcm files from "/root/sipp-3.7.2/ADF/wave_files/English/' folder. Please edit the location of the folder as you need to.
SIPp scenario files rely heavily on the RestyTesty tool. Each User Journey profile is dependent on pre-conditions set up per endpoint. Example, to execute User Journey #1, we use 9193453301 as our ANI. Another example, to execute User Journey #11, we use 9193453311 as our ANI or the phone number of the SIP Client which originates the call into ICX.
The pauses account for the latency and length of the menu-prompt announcements per each step as observed in the SF QA Lab. These will likely require adjustments to match the deployment. For load testing, these hard-coded pauses were replaced by pauses until reception of SIP-INFO messages from ICX.
